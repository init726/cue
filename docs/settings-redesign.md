# 설정 목록 개편

## 참고한 상용 앱

2026-10-28 공식 웹 도움말 기준 조사. 기기에서 앱을 직접 실행해 비교한 결과는 아니다.

- Google Calendar: 일반 설정과 캘린더별 설정을 구분하며 테마는 별도 설정 단계에서 선택한다.
  - https://support.google.com/calendar/answer/6084644
  - https://support.google.com/calendar/answer/15240542
- Todoist: 설정의 Theme에서 테마와 시스템 테마 연동을 관리한다.
  - https://www.todoist.com/pl/inspiration/hidden-features-todoist

이를 참고해 Cue는 첫 화면에 카테고리와 현재 상태만 표시하고, 선택한 항목의 상세 설정을 연다. 아래 분류는 Cue의 기존 기능을 기준으로 정한 설계다.

## 이번 구현

| 첫 화면 목록 | 상세 항목 |
| --- | --- |
| 캘린더와 알림 | 저장할 캘린더, 기본 알림, 종료 시간이 없는 행사의 기본 일정 길이 |
| 화면 테마 | 시스템, 라이트, 다크 |
| 추천 | 관심사 기반 추천, 행사 추천 표시, 관심사 기록 초기화 |
| 내 데이터 | 사진·문서 전송 안내, 익명 계정과 기록 복구 한계, 접힌 개발자 정보, 연결 재확인 |

- 저장 로직과 기존 설정값을 유지한다.
- 상세 화면의 ‘설정으로’와 시스템 뒤로가기로 목록으로 돌아간다.
- 관심사 초기화는 기존 확인 대화상자를 유지한다.
- 일정·추천 갱신은 해당 탭에서 제공한다. 연결 재확인은 내 데이터에서 제공한다.

## 사용자 발견 기반 추천과 연결할 다음 단계

설정 화면 개편과 별도 기능으로 구현한다. 현재 작동하지 않는 옵션을 미리 노출하지 않는다.

- 추천: 학교·캠퍼스, 활동 지역, 관심 분야를 실제 프로필 API와 연결.
- 내 데이터: 행사 정보 공유 범위와 추천 활용 동의를 실제 공유 모델과 연결.
- 개인 일정과 공유 행사 원본을 분리하고, 원본 행사 ID를 보존.
- 유사 환경의 참여 가능 행사 필터링 후 집단 저장 신호를 추천에 반영.

## 검증

기존 테마 위젯 테스트를 새 진입 경로로 수정하고 첫 화면 항목, 상세 설정 숨김, 테마 저장과 목록 복귀 확인을 포함했다.
Flutter SDK가 설치된 환경에서 `flutter analyze` 및 `flutter test` 실행이 필요하다.
