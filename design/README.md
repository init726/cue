# Cue 디자인 시안

`cue-preview.html`을 브라우저로 열면 된다. 빌드나 서버가 필요하지 않다.

## 포스터 없는 기본 화면

- 홈: 촬영 진입점과 다음 일정. 실제 행사 이미지나 가상의 포스터를 표시하지 않는다.
- 발견: 날짜 블록, 제목, 시간·장소, 행사 형식·참가비, 출처와 추천 이유.
- 상세: 제목과 날짜를 중심으로 구성한 헤더, 장소, 참가비·참가 대상, 설명.
- 데스크톱에서는 세 화면을 나란히 표시하며, 모바일에서는 상단 화면 선택으로 전환한다.

`cue-no-poster.css`와 `cue-no-poster.js`가 포스터 없는 화면을 구성한다.
원본 사진을 선택하는 미리보기 기능은 유지하지만 행사 카드에는 이미지를 사용하지 않는다.
행사와 학교·지역·추천 이유는 예시다. 저장·공유·환경 변경은 로컬 브라우저에만 반영한다.

## Flutter 반영 범위

`lib/cue_event_identity.dart`에 이미지 없이 정보를 배치하는 카드 헤더를 만들고,
`lib/main.dart`의 추천 카드와 저장 일정 목록에 연결했다. 날짜 블록·행사명·시간·장소·출처·분야·참가비를 표시한다.
추천의 주요 행동은 일정 추가이며, 관심 없음·원 안내는 더보기로 옮겨 버튼 밀도를 낮췄다.
기존 동선 보기와 행사 확인 단계는 유지한다. HTML 상세 화면 전체가 Flutter에 구현된 상태는 아니다.

## 확인

Edge에서 출처 필터, 저장·취소, 공유 확인, 환경 편집, 모바일 상세 진입·복귀를 확인했다.
1440px, 1024px, 390px 화면에서 페이지 가로 넘침과 JavaScript 오류가 없음을 확인했다.
Flutter SDK가 없는 환경이므로 앱 분석·위젯 테스트·실기기 확인은 남아 있다.
